# Horizon

Horizon est le thème front polyvalent de HiddenCMS. Il propose une base sobre et responsive adaptée aux sites éditoriaux, vitrines, communautaires et institutionnels.

## Installation

```bash
composer require hiddencms/horizon
php tools/addons.php sync
```

Activez ensuite Horizon depuis l’administration, dans **Thèmes & Addons**.

## Personnalisation

Le thème permet de régler les couleurs principales, la couleur du texte, la couleur de fond et la largeur du contenu depuis l’administration.
